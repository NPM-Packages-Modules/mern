# routecheck

```bash
npx @mr-aftab-ahmad-khan/routecheck generate ./dist/server.js
```

Exports an Express **`app`** (default or `app`) and emits a **Vitest** file full of `it.todo` placeholders—your AI agent or team can fill in assertions.
