# Changelog

## [0.1.0] — 2026-05-15

### Added

- `PromptForge` with versioned `create`, `load`, `render`, `rollback`, and `list`.
- Pluggable storage: `FileStorage`, `MemoryStorage`.
- Provider wrappers for OpenAI and Anthropic plus A/B test assignment helpers.
- CLI: `prompt-forge init | create | rollback | list`.
