# reactstatex

**Topics:** `express` · `mern-packages` · `merndev` · `mongodb` · `nodejs` · `npm-pm` · `observability` · `reactstatex` · `typescript`

Auto-generate React state management from APIs.

## Features

- hooks generation
- caching
- optimistic updates
- loading states
- mutation helpers

## Example

```ts
import { reactstatex } from "@mr-aftab-ahmad-khan/reactstatex";

reactstatex.create("/products");
```

## Why

Frontend state management remains repetitive.
