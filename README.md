All **MERN / Node.js** npm packages. One folder = one [org repo](https://github.com/orgs/NPM-Packages-Modules/repositories).

```bash
npm run build --workspace=mern/monguard
node ../.scripts/sync-workspace-repos.mjs mern/monguard
```
